# 视觉读取与结构核验

目标是减少专家描述文件的劳动，而不是增加截图上传问卷。先自动查看input与reference的画面，再结合结构证据推断任务。截图可改善内容与空间关系的理解，不替代精确几何或内部结构验证。

## 默认读取路径

1. 识别真实格式与已有工具。区分缺依赖、格式不支持、文件损坏、缺链接/字体、渲染异常；不能仅搜索不到命令就断言文件打不开。
2. 对可直接查看的图像实际打开；其他格式优先用本地解析或渲染工具输出页面/画板/视图。工具生成图像成功后必须实际查看，不能把存在PNG当作已读画面。记录原文件、页码/画板/视角及渲染方式。
3. 不能直接读取时，在隔离目录转换副本，再解析和渲染。已获环境准备授权时主动补必要可信依赖，不反复让专家处理安装问题；新许可、付费、第三方上传或超出权限的操作另行确认。工具的版本与用法不确定时查官方说明，不猜命令参数。
4. 本地转换失败且已有权限、软件和控制工具支持时，尝试原生软件读取副本并截图。禁止保存、修复原件或影响当前打开的用户工程。自动audit/repair默认关闭；不通过悄悄修复掩盖输入缺陷。
5. 一条首选链路和一条合理备用链路失败后，按错误原因决定是否还有明显可修复的环境问题；不反复执行相同失败命令或无限搜索工具。只对阻塞成题的剩余缺口请求专家提供具体视图/导出/确认，不笼统要求把全部文件转换一遍。

截图不是绕过解码的手段：无法渲染时仍需合适的读取器或软件。skill不自带这些软件，不能将约定的读取路径说成已安装或已实测可用。

## 看全貌，再看局部

- 同时观察input与reference中对应的页面、画板或对象，不只看成品。区分已有内容、新增内容和改动，避免高估工作量。
- 先看全图确定组成，再按问题放大文字、连接处、尺寸与局部接缝。不从模糊缩略图猜文案、数字、单位或符号；OCR只是辅助，与可见画面或结构文字交叉核对。
- 多页先检查页面清单与全页预览，按需要查看细节；三维补必要视角，隐藏部分不默认合格；视频先看覆盖时间范围的帧，再检查关键变化片段，涉及连续动作或声音须查看相应片段。抽样须记覆盖范围，不冒充完整检查。
- 默认渲染不切换隐藏对象或修复丢失资源。结构分析可另查隐藏内容及依赖，但不能把诊断视图当成原始交付画面。

## 各类证据的边界

| 对象 | 画面适合确认 | 还需要结构或其他证据 |
| --- | --- | --- |
| 平面设计/排版 | 必有内容、空间关系、遮挡、可读性、配色方向、合成接缝 | 图层可编辑性、字体名称、图片嵌入、隐藏内容、精确色值 |
| 工程图/CAD | 视图组织、构件表达、标注位置、测距依据是否可见、明显图面冲突 | 真实几何距离、公差、实体交叠、尺寸关联、单位/比例及对象类型 |
| 三维 | 外形、可见装配关系、材质、可见缺件 | 内部结构、拓扑、实际尺寸、可编辑性与隐藏部件 |
| 动画/视频 | 构图、字幕、可见状态、观看片段内的运动 | 全片连续性、音画同步、工程结构、未观看时间段 |

标注显示6.00不证明几何距离为6.00；截图量像素不能验证0.01毫米公差。预览正常不证明源文件图片已嵌入，图层面板截图也不充分证明所有对象可编辑。转换或替代渲染出现缺字、偏移、空白等先排查工具兼容性，不能直接归罪于原reference。

评估有效图像清晰度时，使用实际置入的图像像素及其缩放后的物理尺寸，纳入扩展画布、裁切和变换；不要把未扩展原图像素直接除以猜测的半幅尺寸，也不把导出dpi当作素材细节。缺实际放置信息时给出有依据的范围或定性风险，不给伪精确数值。低于某个ppi不自动等于不可用，以已确认用途和接受标准判断；接受例外不等于当前文件已验证符合。

## DWG处理方向

可用时优先在副本上通过可信DWG转换器转为DXF，再提取实体、图层、文字和尺寸并渲染；例如ODA转换器配合ezdxf。LibreDWG等可作为适配情况下的备用。具体支持范围依当前工具与文件版本确认，不承诺所有实体无损。

转换成功后检查告警、模型/布局覆盖、代理或不支持实体、外部依赖、文字及尺寸遗漏。解析DXF的能力不等于直接读取DWG的能力；二维渲染也不能证明复杂三维实体已完整还原。

## 内部读取记录与最少人工

每个关键结论记录：源文件与对象定位、视觉证据、结构证据、状态（已验证/部分读取/失败）、剩余缺口。只向专家说影响任务的具体事项，不输出技术流水账。

文件显示的设计选择不自动成为硬约束。已确认的规范直接沿用；从画面提出的必要候选边界需专家确认，可选细节不追问。不要把材料完整查看变成逐项让专家重复确认看得见的事实。

即使无法完整解析，也应分开处理：已知内容直接整理；关键内部结构需要人工核验则提出具体检查点；任务核心完全未知才暂停成题。不能用末尾一句“尚未核验”掩盖已知矛盾或关键要求缺失。

图像理解还要服务于交付质量：尺寸是几何关联对象还是普通文字、哪些部分需可编辑、标识/图层怎样区分、源文件能否自包含，这些不能被详尽的业务参数挤掉。附件已经完整规定的参数只需明确引用，正文优先补必要交付边界，不大段复述附件来制造完整感。
