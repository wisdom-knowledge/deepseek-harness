# 随包生产与审核规则

依据项目方提供的《Pale ale-生产规则指南-0731》《Pale ale-审核规则指南-0731》及本次出题访谈约定整理。不是线上规则已更新的声明；两份文档存在的“唯一解”字面表述，按审核文档及项目方明确解释执行：有边界但不要求唯一答案，也不要求唯一路径。原指南AI辅助禁令与访谈试点授权的差别须如实保留。

另按项目方指定，仅采纳《ALE产线规划及机审规则v1.0》的经济价值判定、难度五维评分及子任务计数定义，详见value-and-difficulty.md。该文其他旧版口径（版本号及步骤写入prompt等）不覆盖现行题面约定。

## 任务成立

- 真实专业工作、具有经济价值，依赖真实分析和软件操作，不是直接从input抄答案或简单算出。软件工作应是主体，不能难度全在软件外的计算、推导或写脚本。
- 任务必须有挑战性，不能只检查字段齐全。五维总分更新后≤1.5属于应排除的Easy；这不是统一的最低小时数、软件数、步骤数或难点数。只收集事实，不凑指标。
- 人审后续会结合模型实际表现判断难度。文件访谈只能识别实质工作与明显不足，不能代替模型实测。
- 多样性涉及同专家其他题目；只看到一个案例不能声称已验证多样性，也不主动读取历史题库。当前题目不能仅以“又一个相同脚本/替换模板”自证挑战性。
- 使用基础软件可完成，不依赖额外插件、导入画笔或裸机不带的字体。具体环境无法确认时保留技术检查点；不能把文件中出现字体名等同于目标环境可用，或认为仅随包附字体就自动合规。

## Prompt

必须明写角色设定和任务目标，工作情境或产物用途不能代替角色；还需软件名称（不写软件版本号）、逐一可对照的输入附件名称/格式/内容/作用，以及最终产物的数量、内容与质量边界、格式、文件名和输出目录output。

- 不含菜单、命令、操作顺序等解题路径；这些单独写在关键做题步骤。结果要求不因听起来像动作而被删除，例如“四个孔的中心距为40×40毫米”是结果约束。
- 只要求最终产物，不要求提交无关的中间产物。需要验证图层、模型结构、表单功能等时，交付格式必须能承载验证；不把PNG预览当作可编辑源文件证据。
- 每个多产物的要求指向明确；不只描述格式、分辨率而不约束实际内容。所需内容、相互关系、适用范围与质量有界，必要的数值、单位、阈值不能漏。
- 规范可以由模型可见的input附件承载，正文明确文件及约束范围；不得要求模型“参照reference”或查看访谈记录。不能把完整答案作为参考素材送给模型以省略题面。
- 保留真实自由度，不从reference照抄所有字体、坐标、色号形成不必要的唯一解。必要尺寸等精确要求仍须保留，不能为自由度删掉。

## 材料

- input与reference分开。input无无关文件、敏感/侵权内容或可读答案；隐藏图层、关闭对象、嵌入预览等也可能泄露答案。已提供的允许模板内容与本题要做的部分区分清楚。
- 每个实际使用的input与prompt一一对应；不要把未使用文件悄悄忽略或声称已从包中移除。请专家确认用途或在交付外指出需要清理。
- input足以独立支撑任务，不缺素材、数据、关联文件；外部图片与文件依赖须完整嵌入。解析工具覆盖不足时，不保证“绝无答案”“全部嵌入”或“原生能打开”。
- reference为专家本人完成的标准样本，满足每条题面要求；文件名、格式、数量、质量一致，无无关备份、缓存、草稿及隐藏残留。源文件和预览分开核对，预览正常不能证明源文件链接有效。
- 文件完整性、尺寸、文字、单位、颜色方向、字体及对象关系能直接查就查。冲突报出并访谈解决，不给reference绝对优先权，不悄悄改写要求消灭冲突。
- 最终打包规范为input.zip内含input/及附件，reference.zip内含reference/及产物；原指南限制input包500M、reference包2G。访谈可接收散文件或其他打包形式，不要求专家先反复整理上传；需要提交前的整理点单列，不擅自打包。
- 真实性、版权/脱敏有材料或专家声明就记录，只有必要缺口才问，不能凭成品自行证明。录屏不是本skill的常规交付，不主动扩展录屏问卷。

## 经济价值与关键步骤

经济价值约50–200字，分别说明执行岗位与工作环节、可量化人工时间或费用、具体重复劳动与专业判断，四项均须落实到该字段正文。具体充分性与补问口径见value-and-difficulty.md。可复用已经确认的流程信息，缺时间或费用只问其中足够支撑的事实，不强求两者、频次和收益率全齐。不虚构节省比例或市场行情。

关键做题步骤按执行顺序覆盖输入到输出完整链路，每步有明确动作，保留关键专业判断，无逻辑断层，不必写逐菜单操作。来源是专家实际过程或其明确说明的拟采用路径；计划不能冒充已完成路径。对于已经提供的reference，实际路径尚未确认时不能称步骤与该reference制作过程一致。
