# 版本记录与回退约定

当前版本：ver0.2

维护源目录使用独立本地Git仓库保留完整版本。版本标签不可移动或覆盖，不推送远端。分发ZIP只包含skill文件，不包含Git仓库、凭据、专家附件、访谈记录或其他skill。

## 安装

将ZIP中的ale-reference-interviewer文件夹完整安装到目标Codex的skills目录（通常为用户主目录下的.codex/skills，设置CODEX_HOME时为其skills子目录）。不要只复制SKILL.md，也不要多套一层同名文件夹。已有同名skill时先完整备份，再替换；不影响ale-task-interviewer或humanizer-seeded。安装后在新会话中使用$ale-reference-interviewer，并上传input和reference；一句话任务描述选填。

本包不含行业软件、文件转换器或运行环境，附件读取能力取决于目标机器可用的工具和授权。技能规则自包含，不需要原项目目录、飞书账号或.env文件。

## 后续修改与回退

- 每次获准优化时，从当前启用版本开始修改。先检查git status，保存未发布改动，不覆盖用户修改。
- 发布新版本时递增版本号，同步SKILL.md与本文件，记录日期、变更、验证范围及已知限制。提交该版本的skill文件并创建同名标签；标签不覆盖、不复用。
- 只有提交、标签和工作区一致，才宣称版本已保存。安装包从对应标签导出，保留旧安装包供回退。
- 仅在用户指定回退目标后执行。维护源目录先保存所有未提交修改，再用git switch --detach <版本标签>，并核对文件和版本号。不执行git reset --hard或强制覆盖。
- 从ZIP安装的副本没有Git历史。回退时先备份当前同名skill，再用指定版本完整安装包替换，避免混入其他版本的文件。
