# 易于专家调整的三字段草稿

## 交付标准

把已经取得的信息组织成专家稍调表达即可使用的内容，不让专家从长文、聊天或多个版本中重新寻找和拼接要求。允许且支持专家编辑，不以“无需修改直接填表”为目标。默认交付三个字段的简洁要点稿，而非长篇代写定稿；执行信息仍须完整，不能退化为关键词或空提纲。内容完成、专家确认、附件核验和审核通过是不同状态。

专家调整的应主要是表达，而不是补设计意图或重新组织验收条件。要点稿本身须在信息与质量要求上达到适用生产、审核规则的成题标准；不以还原旧题、收齐专家已有回答或列出足够多的条目替代这一目标。必要缺口通过定向访谈补齐，不靠助手脑补，不因采用bullet points而降低内容标准。

## 默认呈现

- prompt：按任务与角色、输入、成品要求、交付要求的自然顺序组织bullet points，不必为每类另起标题。每条是可独立理解的完整要求，相关参数可以同条列出，不用分号藏一长串不同主题。
- 经济价值：用少量要点整理真实工作场景、已有工时或成本、重复工作及协作价值，不写宣传性段落，不要求专家自行从步骤推导价值。
- 做题步骤：按实际先后用有序列表，每步简短说明关键动作，必要时保留专业判断或易错点。
- 不把长段落简单加上项目符号冒充精简；合并重复信息，去掉讨论和解释。条数服从实际要求，不拆成几十个碎片，也不为限制条数漏要求。
- 专家要求连贯文字时，才把同一组信息改为短段落，不新增事实。默认只展示一个版本，不同时输出长文与要点让专家再次选择和对照。

## 先整理要求，再写正文

从需求记录中区分必须满足的结果、输入与交付规范、有用的偏好、解释与讨论、操作路径。不要沿聊天顺序逐段扩写。

- 结果与技术规范进入prompt，保留准确数量、单位、名称、关系、范围及约束强度。可以合并，不可用泛称替代具体要求。
- 专家确认过的解释不必全文进入题面，只保留影响执行或验收的部分。有用偏好简短表达；重复的舒适性描述、赞美和讨论经过留在内部记录。
- 规范附件可承载详细要求，但prompt须标明文件和适用范围，执行者确实能取得它。不能指向未提供文件或reference，不能为缩字数新建未经确认的规范附件。
- 路径进入步骤，专业判断与重复劳动支持经济价值。同一事实跨字段承担不同用途可以出现，不重复整段。
- 任务阶段若影响交付深度，开头一句说明。核验限制放在三字段之外，不反复写后续调整、免责声明或“有问题再讨论”，不能借此放宽硬要求。

## 篇幅预算

先追求要点清楚、无需重新拼接，不设必须写满的字数。以下仅是成段稿的编辑参考，不用于把默认要点稿扩写成长文，也不可靠删必要要求达标：

- prompt通常400至800字左右，简单任务可以更短。超过1000字先压缩复查，只有真实要求或输入清单确需长文时才保留。800字不是必须填满的额度。
- 经济价值50至200字，通常一段足够。说明真实工作成本及模型协作的具体用途，不虚构收益或节省比例。
- 步骤通常4至7步，每步一至两句，随实际流程调整，不拆分凑数，不合并到丢失关键动作或易错点。

压缩顺序：删除访谈叙事与重复声明，合并重复要求，删除不影响选择的偏好，把可唯一算出的展开值收回为原始参数加容差，最后缩短句式。存在实质歧义的计算口径仍须保留，必要公式不因篇幅删除。准确文件名、指定图层等不可省清单可紧凑列举。

prompt每句应承担背景、输入用途、结果要求或交付规范之一。不能说明用途的句子删除或移入内部记录，不是每个回答都需要进入题面。

## 展示前检查

质量收尾按访谈节奏的三类处理：已有要求可直接消歧；必要新边界须明确确认；无需增加的细节不补。候选建议未确认前不进入三字段，不能借润色或整体确认升级为硬要求。原题更详细不代表新稿缺项。偏好保持原强度，可删纯粹重复的尾句，但不能连同专家独立提出的能力要求一起删掉。

1. 独立可执行：角色、软件、目标、输入作用、主要内容和交付条件清楚，无“见上文聊天”、必要附件缺失、占位或尚需临场协商的核心决定。
2. 必要要求无损：已确认需求逐条对回prompt或明确引用的input，尤其检查单位、文件结构、必有内容、对应关系和指定名称。遗漏先补回，不让专家最后确认时承担找漏项的工作。
3. 有据且一致：不把惯例、建议、reference偶然属性当硬要求，不新增未经同意的指标，不把“必须”改为“尽量”。明确变更需同步三字段及材料。未经核验的规范引用不能包装成已验证事实；若正确性决定任务能否执行，先解决，不能用收尾提示掩盖。
4. 自由度与验收边界：产物的必要内容、对象关系、技术要求和视觉质量均有足够依据，可允许无数种合格表达。边界可由语义、区域、效果或经确认的附件表达，不强求数值，也不只留下“协调、合理”。只补问影响成品合格与否的实际缺口，不穷举反例，不擅自排除审美质量。文字缩短或专家整体确认都不自动解决信息缺口。
5. 字段各司其职：prompt给结果，步骤给有来源的完成路径，经济价值解释真实工作成本与协作价值。步骤中的结果条件须在题面可见，不得虚构工时或收益。
6. 足够短：按预算去掉无效内容，再检查完整性。字数达标不代表质量合格，超目标也不自动代表不可用。

能从已有证据修好的先内部修好，缺少必要事实的只补问该缺口。有任务阻塞只能称待补工作稿，不能称可直接使用。原生核验或分发授权等边界如实单列，不伪装完成，不因此反复扩写prompt。

最终只展示三字段要点稿和一句请专家确认或调整表达的请求；专家要求段落时才输出段落稿。确有材料或授权边界时附最短具体提示，不输出检查表、修订过程或自评。保存正文必须与专家看到的版本一致。
