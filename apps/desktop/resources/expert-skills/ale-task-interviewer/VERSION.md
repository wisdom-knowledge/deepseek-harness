# 版本记录与回退约定

当前版本：ver0.1

本目录使用独立本地Git仓库保留完整版本。版本标签不可移动或覆盖，不推送远端。

## 后续修改

- 每次获准优化时，从当前启用版本开始修改。先检查git status；未发布改动先确认归属并保存，不覆盖用户修改。
- 每次优化递增版本号（ver0.2、ver0.3等），同步SKILL.md的版本标记与本文件，记录日期、变更内容、验证范围及已知限制。
- 完成检查后提交所有属于该版本的skill文件，并创建同名Git标签；只有提交、标签和工作区一致才宣称版本已保存。
- 不将专家材料、凭证、访谈记录或机审文件放入本仓库。版本仅覆盖本skill，不包含独立humanizer-seeded。

## 回退

仅在用户指定回退目标后执行。先检查工作区，保存所有未提交修改；不执行git reset --hard或强制覆盖。
工作区干净后使用git switch --detach <版本标签>启用指定版本，再核对完整文件清单、内容及版本号。
后续优化使用未占用的新版本号，不复用被回退版本之后的已有标签。用git tag --list 'ver*'查看全部历史版本；分离HEAD不妨碍按新标签保存后续版本。
